# BrightSteps — Unified Four-Game Parent Platform

This project combines four child-friendly prototype games into one Flask platform with:

- Parent registration and login
- SQLite database with password hashing
- Multiple child profiles (ages 5–10)
- One dashboard to launch all four games
- Unified result storage
- Parent report and session history

## Games
1. Reading Adventure — literacy/reading prototype with domain-level responses
2. Treasure Number Race — number comparison/number-sense prototype
3. Focus Balloon Pop — selective attention/reaction-time prototype
4. Memory & Pattern Quest — working-memory/sequencing prototype

## Run on Windows
Open Command Prompt in this folder:

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000` in Chrome.

## Important
The games are screening/learning prototypes, not diagnostic tools. The displayed metrics are descriptive and should not be treated as clinical cut-offs.
